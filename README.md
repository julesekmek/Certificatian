# Certificat Persona 2.0

Générateur de certificat de participation à l'atelier **Persona 2.0** (AI Discipline × Cardiweb), animé par Jules Ekmekdjian et Thibaut Sainrat.

Les participants scannent le QR code présenté en fin d'atelier, saisissent leurs informations, génèrent leur certificat et le partagent sur LinkedIn.

- `index.html` : la page du générateur (aucun serveur, tout est généré dans le navigateur).
- `qr.html` : affiche le QR code de l'adresse du site.

Pour changer la date de l'atelier : dans `index.html`, modifier `dateAtelier` dans le bloc `CONFIGURATION`.
